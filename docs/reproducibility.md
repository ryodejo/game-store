# Проверка документации и запуска

Дата: 04.10.2026. Функциональность, дизайн, рабочая база и `legacy/` не изменялись.

Сборка выполнена на копии отслеживаемых исходников, без `legacy/`, локальных реквизитов и старого `target/`. Использованы JDK 25.0.2 (компиляция release 17), Maven Wrapper/Maven 3.9.9 и PostgreSQL 17. Интеграционные тесты использовали отдельную `gamestore_test` со случайными схемами. Проверочный сервер получил собственную схему в этой тестовой базе.

| Выполненная проверка | Результат |
| --- | --- |
| `java -version` / `javac -version` | JDK доступен |
| Maven Wrapper `-B verify` | BUILD SUCCESS |
| JUnit и PostgreSQL-интеграция | 35 тестов; ошибок, падений и пропусков нет |
| Миграции V1–V5 в пустых схемах | Применились |
| Сборка shaded JAR | Успешно |
| Запуск `ServerMain` из JAR на проверочном порту | Успешно |
| Настоящий TCP-запрос `CATALOG` | Успешный ответ |
| PowerShell-скрипты БД | Синтаксис корректен; загрузка существующей локальной конфигурации работает |
| README и setup: относительные ссылки | Файлы существуют |
| `git ls-files` и `git check-ignore` | Локальные реквизиты, данные, legacy и результаты сборки не отслеживаются и игнорируются |

Первичная установка нового кластера через `local-db.ps1` в этой проверке не запускалась: использован уже работающий отдельный PostgreSQL проекта, без изменения системного сервера и рабочей `gamestore`. Альтернативный сценарий с внешним PostgreSQL в setup документирован по фактическим переменным и требованиям, но не выполнялся.

Клонирование с GitHub не выполнялось: использованы текущие отслеживаемые файлы, URL проверен по origin. Зависимости Maven доступны через локальный кеш; загрузка всех зависимостей на совершенно новом компьютере отдельно не проверена.

Swing проверен существующими headless-тестами, включая интеграцию UI/TCP/БД. Новый интерактивный запуск клиента и визуальный просмотр не выполнялись; основной существующий скриншот сохранён. SMTP в проекте не реализован. Предыдущие проверки описаны в [VERIFICATION.md](VERIFICATION.md).

Проверочный сервер остановлен, его временная схема удалена. Этот отчёт фиксирует проверки приложения до оформления документации в Git; результат последующей отправки коммита сообщается отдельно.
